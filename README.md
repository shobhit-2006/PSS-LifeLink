🏥 PSS LifeLink

Hospital  Discovery & Organ Availability System

Connecting Hospitals with the People Who Need Them.

PSS LifeLink is a hospital resource discovery system developed as a B.Tech mini-project. The project aims to help users find hospital information and check the availability of specific organs and blood groups through a structured database.

By combining C++, Object-Oriented Programming (OOP), MySQL and web technologies, PSS LifeLink aims to make hospital resource information easier to search and understand.

---

📌 Project Overview

Finding information about hospitals and the availability of essential medical resources can be challenging. PSS LifeLink provides a centralized approach to organizing hospital details, organ availability and blood bank information.

Users can search using a Hospital ID and view the corresponding hospital information, available organs and blood group quantities stored in the database.

«Project Focus: Hospital information, organ availability tracking and blood bank resource lookup.»

🗄️ Database Overview

The project database is designed to organize three main categories of information:

- Hospital: Hospital ID, name, city, address and contact information.
- Organ: Organ name, availability status and quantity.
- Blood Bank: Blood group and available quantity associated with a hospital.

SQL queries can retrieve the relevant hospital details and resource records based on the selected search criteria.

🚀 Getting Started

Prerequisites

- A C++ compiler compatible with the project.
- MySQL Server and MySQL Workbench.
- MySQL Connector/C++.
- A web browser for the HTML frontend.

Setup Instructions

1. Clone or download this repository.
2. Open MySQL Workbench and create the project database.
3. Review the SQL script and execute it in your MySQL environment.
4. Configure the MySQL connection settings for the C++ application.
5. Configure the required Connector/C++ libraries.
6. Compile and run the backend using the project's build configuration.
7. Open the HTML frontend in a web browser.

Additional configuration may be required depending on your system and deployment environment. Refer to "README-DEPLOY.md" for deployment-related instructions.
